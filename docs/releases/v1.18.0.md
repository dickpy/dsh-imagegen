# v1.18.0 · 独立反推工作台与暗色体验修复

- 顶部新增「反推提示词」独立 Tab，提供左侧选图与参数、右侧可编辑结果的页内工作台，不再使用弹窗。
- 支持上传、拖放和粘贴图片；先选择详细程度、输出语言与额外要求，再手动开始反推。结果可查看、编辑、复制，只有点击「填入提示词」才回填，不会打开即执行或自动覆盖原提示词（#81）。
- 参考图、生成结果与预览入口统一跳转到工作台；切换 Tab 保留草稿，更换图片后丢弃旧请求结果，回填保留原生图/电商业务模式。
- 移除底部重复工具栏：素材库保留顶部入口，模板恢复悬浮入口。
- 修复暗色主题下底部主按钮文字不可读，明确配对按钮背景、文字及禁用状态颜色。
- 修复宿主侧栏容器限制历史区域高度、外层滚轮拦截导致历史难以滚动的问题，并压缩历史卡片间距（#79）。
- 模型检测兼容百炼 DashScope 原生 `output.models[].model` 响应，保留原生生图地址，不影响已有 OpenAI 格式（#80）。

## 验证

类型检查、构建、完整单元/远程接口/DOM 回归、冒烟检查通过。最终修复提交已通过 Chromium 工作流，覆盖历史栏受限高度与外层滚轮拦截、原有生图工作台、反推手动执行/回填/源图更换、明暗主题按钮对比度和窄屏布局。接口使用本地夹具，不消耗上游模型额度。
