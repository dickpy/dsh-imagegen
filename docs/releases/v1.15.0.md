# v1.15.0 · 生图配置进「插件」页（多 tab），设置页界面重做

## 1. 设置 → 插件：新增「生图配置」标签页

注册到 DSH 的 `settings.plugins.tab` 插槽（与 `settings.section` 同一套 slots 契约），
在「设置 → 内置插件」里多出一个「生图配置」标签页，内容按四个子 tab 组织：

| 子 tab | 覆盖的配置 |
| --- | --- |
| 渠道与模型 | 渠道列表与密钥、默认生图模型、提示词增强模型 |
| 存储与同步 | 本地路径、对象存储开关 / endpoint / region / prefix / AK / SK、同步范围、连接测试 |
| 画布技能 | 技能总开关、长任务、白名单、输出目录、超时、Agent 预设、重任务探测 |
| 通用 | 插件启用、向系统提示词宣告、允许 Agent 生图 |

- 与「设置 → 生图配置」共用**同一个 controller**：两处看到的草稿是同一份，一处改动另一处刷新即同步。
- 宿主没有这个 slot（旧版本 DSH）时注册失败只打一条 warn，不影响 GUI 启动。

## 2. 「设置 → 生图配置」界面与交互重做

- 顶部**概览条**：渠道 x/y 可用与模型数、提示词增强模型、存储开关、画布技能开关、通用开关 + 健康徽章；
  点任一块直接跳到对应分组。
- 分组改成卡片：标题行 + 一行说明 + 状态徽章；当前分组左侧 2px 品牌色强调条；组间距 16px。
- 字段行统一「label 在上、hint 在下、控件右对齐」，控件列最宽 280px；窄屏（<720px）回落单列。
- 保存栏吸底（sticky + 毛玻璃 + 细分隔线），带「有未保存的修改 / 已保存」状态，不再遮挡最后一个字段。
- 颜色全部走 `--dsw-alias-*` 变量，深色主题跟随；未新增任何硬编码主题色。

## 3. 兼容性

- 所有字段 `id`、`onEdit` / `resetField`、`data-*` 测试钩子原样保留；smoke **一行未改**仍 95/95。
- 两个入口渲染的是同一份实现（`ImageGenSettingsSurface`），没有复制内容，打包后字段 id 各只出现一次。
- 存储/画布技能里与「图片转 PPT」相关的四个字段仍保留在「画布技能」tab 下（宿主能力仍在，界面入口已按 v1.14.0 移除）。
