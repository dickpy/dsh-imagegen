# v1.14.0 · 移除图片转 PPT，新增提示词反推

## 图片转可编辑 PPT：从界面移除

两天里把它做到了「能用」，但真页面的还原质量仍不稳定（卡片、表格、插画只能近似，图为主页面还要依赖图像后端与额度），
按「做不好不如不显示」的意见，把它的所有入口从界面上去掉了：

- 顶部工作区不再有「图片转 PPT」标签页；
- 生图结果、多模型对比、放大预览里不再有「生成可编辑 PPT」按钮；
- 设置里不再有「图片转可编辑 PPT」分区；
- 无限画布的技能菜单不再出现 `ppt.fromImages`。

宿主侧实现（本地管线、验收、路由、`editppt` 运行时安装）都保留着，只是不再默认展示：
需要时把设置里的 `pptModeEnabled` 打开即可恢复画布技能入口（工作区界面需要回滚这次客户端改动）。
代码与设计见 [本地管线说明](../ppt-local-pipeline.md)，历史结论见 [PPT模式说明](../ppt-mode-review.md)。

## 新增：提示词反推（image → prompt）

选一张图，把它翻译成一段可以直接生图的提示词。

- **具体而非堆砌**：镜头/景别（85mm、f/1.8、浅景深）、光线方向与质感、材质、配色、媒介与风格；
  明确禁止「高清 8K 杰作」这类空词，也不编造品牌与水印。
- **图上文字照抄**：海报、封面、界面里的文字原样引用并说明位置层级。
- **三档长度**（精简 / 标准 / 详尽）× **三种输出语言**（跟随界面 / 中文 / English）。
- **可加要求**：如「保留风格与配色，主体换成猫」。
- 结果可「填入提示词」继续生成，或复制走；一次可反推多张参考图（第一张定主体与构图，其余提供风格线索）。

入口：
- 生图结果卡片 / 多模型对比卡片 / 放大预览的「反推提示词」按钮（替代原来的 PPT 按钮位置）；
- 无限画布任意图片节点 → 技能 → 提示词反推（产出文本节点）。

实现：宿主 `SkillRunner.reversePrompt`（画布技能 `prompt.reverse` 与独立接口 `POST /api/dsh-imagegen/reverse-prompt`
共用同一次模型调用），沿用「提示词增强」配置的**可读图聊天模型**；未配置时按钮给出明确提示而不是静默失败。

## 实测（本机，gpt-6.1-sol）

| 输入 | 参数 | 耗时 | 结果 |
| --- | --- | --- | --- |
| 二次元直播封面（含日文排版） | standard / 跟随界面 | 42 s | 307 字中文提示词：人物、构图、配色、光线、风格齐全，并把「まったりおしゃべりしよ〜♡」「雑談配信」等文字原样抄入 |
| 同上 | brief / English +「主体换成猫」 | 36 s | 479 字符英文提示词，主体已替换为猫，风格与配色保留 |

测试：`node scripts/reverse-prompt.test.mjs`（5 个用例：参数进入 system、去围栏、多图与额外要求、
空回答/报错/超量、非图片资产拒绝）、`node scripts/reverse-prompt-live.mjs <图片>` 可对任意图片复现上表。
