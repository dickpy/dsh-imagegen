# v1.18.1 · 提示词增强模型：保存、渠道复用与检测修复

- 修复「获取可用模型」在未保存或未配置时报 `API URL is required`：检测现在直接使用设置卡片里的草稿（渠道选择 / 自定义地址与密钥），不再只读上一次保存的结果。
- 新增「接口来源」选择：复用生图渠道（可选具体渠道，默认自动跟随默认渠道）或独立对话 API；所选渠道写入新设置项 `promptChannelId`，宿主按它解析对话端点。
- 复用渠道只列出可用于对话的 API 密钥渠道；订阅登录渠道与填写了完整接口地址的渠道会标注原因并禁用，避免选到必然失败的行。
- 模型候选列表新增按名称筛选、已显示数量提示，长列表不再一屏铺满；检测后显示检测来源（渠道名或独立地址）。
- 提示词增强分组内新增「保存修改」按钮与未保存提示，不必再滚动到底部保存；失败时显示「保存失败」。
- 配置类错误改为结构化错误码（`prompt-url-missing` / `prompt-channel-unsupported`），由界面渲染中文/英文/俄文提示，不再把宿主的英文异常原文抛到设置页。
- 对话端点解析新增 `resolvePromptEndpoint`（返回来源与不可用原因）；`resolvePromptModelConfig` 保持原返回值不变，另有显式渠道与草稿覆盖的冒烟用例覆盖。
