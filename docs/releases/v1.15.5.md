# v1.15.5 · GPT Image 分辨率与参考图输入修复

- **修复 #63：2K / 4K 只改变画质、没有改变实际尺寸。** GPT Image 2 系列现在按比例与清晰度发送真实像素尺寸；16:9 的 2K 为 2560×1440、4K 为 3840×2160。全部 8 种比例均受 16 像素对齐、3840 最长边和 8,294,400 总像素预算约束；方图 4K 为 2880×2880。1K、自动档、GPT Image 1.x 和其他兼容模型保留原行为。
- **修复 #65：拖入参考图后，DSH 全局文件拖放提示层无法退出。** 参考图框在消费落下事件后通知宿主结束拖放，清除宿主的嵌套拖入计数；参考图不会误加到会话，宿主其他区域的文件拖放仍可正常使用。
- **增加粘贴图片入口。** 图生图参考图区域提供「粘贴图片」按钮，也继续支持在参考图区域或提示词框按 Ctrl/Cmd+V。无图片、无剪贴板 API 或权限被拒绝时显示说明；格式、数量及大小限制与上传一致，清空参考图会取消尚未完成的粘贴。
- **增加清空提示词按钮。** 单独清空文生图／图生图的提示词并返回输入框焦点，保留参考图和生成参数。
- 修正打包校验中已经移除的独立 PPT 页面断言，改为校验现有画布技能任务界面。

验证覆盖类型检查、构建、29 项单测、三组 DOM 端到端回归、95 项构建产物冒烟检查及实际 npm tarball 校验。新增拖放回归模拟 DSH 的 document 监听与 window dragend 清理机制，覆盖外部拖入、嵌套与连续拖放、错误文件、取消和宿主会话区拖放；剪贴板回归覆盖按钮／键盘输入、失败提示与异步取消。

另通过 Chromium 组件回归，验证真实剪贴板 API 读写、外部文件拖放生命周期、多图上传与限额、预览键盘操作，以及移动端和深色布局。

GPT Image 高于 2K 的尺寸是上游实验能力，最终支持情况取决于渠道。本次未进行官方 API 真实出图验收。
