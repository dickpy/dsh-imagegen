# v1.22.0 — 生图专用左栏、可配置下载超时与数值设置修复

## 新增

- **生图时接管左侧栏（默认开启）**：打开生图后左栏只留生图历史，顶部一个「回到对话」；宿主的面板列表、品牌行与「新会话」暂时让位。装多少插件（插件 / 自动化任务 / 终端 / 文件 …）都不会再挤矮历史——六个面板时历史区从 502px 涨到 772px。
- **适配 dsh-islands-ui 等皮肤**：接管时把皮肤为品牌行预留的栅格行（5px + 36px）一并收为 0，顶部不再空一块；皮肤自带的收起按钮保留并停靠在右上角。
- **结果图下载超时可配置**：设置 → 生图配置 → 渠道 → 「结果图下载超时」，范围 10–600 秒，默认 60。下载超时的报错会写明当次预算和调整位置，不再只给一个 AbortError。

## 修复

- **收起侧边栏按钮消失（#101 报告后回归）**：上一版接管把 `logoRow` 整行隐藏，而官方壳的收起按钮正是该行的子元素，按钮随之消失。现在只隐藏品牌字，按钮原地留用并浮到右上角，仍走宿主自己的折叠逻辑。
- **数值类设置存不进去**：设置卡片里「每页并发数」「单页预算（分钟）」「重任务超时（分钟）」原本用文本字段写入字符串，宿主的 `z.number()` 校验会拒绝，保存只显示「未保存」。现新增带范围校验的数值字段类型，上述三项与新的下载超时统一走它。

## 说明

- 「生图时接管左侧栏」默认开启；想恢复 v1.21.x 的并列布局，在「设置 → 生图配置 → 通用设置」关闭即可，随时可改回。
- 侧栏折叠状态下历史宿主不显示，返回对话用工作室头部的「对话」按钮，展开用原生收起按钮。
