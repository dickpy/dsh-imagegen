# v1.15.6 · 生成结果显示耗时

- **实现 #66：已生成图片右下角常驻显示「耗时 X分Y秒」。** 文生图、图生图、多模型对比、电商套图及素材库共用耗时角标，全屏对比也保留各张图片的计时。
- **每个任务独立计时，完成后固定。** 先出图的模型会立即显示自己的耗时，不受其他模型继续生成、失败或取消的影响；同一请求批次的图片共享该次生成耗时。
- **历史恢复和收藏后保留耗时。** 时间作为图片元数据保存，重新打开历史或加入素材库后仍可查看；旧记录和本地上传图片没有计时数据时不显示角标。
- 计时使用宿主的单调时钟，覆盖生成请求及结果下载，不包含排队和历史保存时间。角标仅作为界面信息显示，复制和下载保留原始图片。
- 同步中文、英文、俄文文案，插件与更新检测版本统一为 **1.15.6**。

验证：类型检查、构建、36 项单测、3 组 DOM 端到端回归、95 项构建产物冒烟检查及 npm tarball 校验。新增回归覆盖独立任务计时、排队与保存时间排除、订阅渠道、保存失败、历史与素材库持久化、旧记录兼容、多模型交错完成和全屏对比。
