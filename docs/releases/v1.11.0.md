# v1.11.0 · 复制图片、隐私模式与订阅渠道修复

## 更新

- **复制图片（#59）**：在文生图、图生图、对比结果和放大预览中，右键图片或点击「复制图片」，可粘贴到其他应用。PNG 保留原始数据，JPEG/WebP 等转换为 PNG；剪贴板权限不足时显示错误，不影响下载。
- **隐藏图片（#60）**：点击顶部「隐藏图片」或按 `Alt+Shift+H`，可暂时隐藏工作室的图片预览，再次操作恢复。工作室历史、对比和放大预览同步隐藏，不删除生成结果。此功能不隐藏 DSH 原生对话中的图片，也不会清空系统剪贴板。
- **订阅渠道 Agent 生图（#57）**：采用贡献者 [@Nyarlathoteppppp 的 PR #58](https://github.com/dickpy/dsh-imagegen/pull/58)，允许已配置的订阅渠道通过 Agent 预检。后续补充了所选渠道检查和文生图、图生图、`/edit_image` 回归；账号登录与凭据刷新仍由订阅管理器负责。
- **图片转 PPT 技能安装**：兼容上游仓库 `skills/image-to-editable-ppt/` 目录布局，并正确处理 GitHub 技能目录链接。上游技能和 CLI 本身没有改写。

## 安装

```bash
dsh plugin --profile web add @dickpy/dsh-imagegen@1.11.0
```

升级后请重启 DSH。剪贴板图片复制需要宿主允许 Clipboard API；不可用或权限被拒时可下载图片。

## 验证范围

类型检查、构建、单元测试、DOM 端到端、完整 smoke 和安装包检查；订阅和隐私/复制入口包含回归用例。技能安装另使用上游真实仓库检查了技能文件及 Python 运行环境安装。

未在真实 DSH Windows 桌面端验证图片转 PPT 的完整上传、生成和下载链路，也未在该宿主实测系统剪贴板；不能据此声称图片转 PPT 已完整跑通。
