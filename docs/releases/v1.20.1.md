# v1.20.1 · 结果板自适应排版与预览拖动

## 结果板排版（#97）

- 排版按张数固定：1 张铺满预览区；2 张左右各半；3 张上二下一；4 张 2×2；5 张上三下二、6 张上三下三；超过 6 张三列并滚动。不再按像素比例自动改变行列，同样的张数永远长一个样。
- 图片始终保持原始比例完整显示（contain），不裁切。
- 历史记录、画廊和单模型结果用的普通结果网格现在和工作室结果板共用同一套排版与下载按钮，不再一处新一处旧。

## 结果卡操作

- 图片右下角的下载按钮与耗时改为**鼠标移入卡片才显示**（键盘聚焦也会显示），不再长期压在图片上占地方；触屏环境保持常显。
- 图片右下角新增下载按钮，位于耗时徽标左侧，单击直接下载原图字节。
- 点开大图后左右方向键可以在本次结果之间切换，不再需要反复关闭再打开。

## 预览（#97）

- 放大后可以按住图片拖动查看细节（光标变为抓手），不再只能靠滚动条；未放大时拖动不生效，普通单击行为不变。

## 下拉菜单（#98）

- 设置壁纸皮肤后，下拉菜单面板不再透出下层内容：选择器触发器与弹层、模型选择弹层改为在皮肤色下方垫一层不透明底色，保留皮肤配色但不透明。

## 加入对话

- 选择目标会话的弹窗重做：可以按标题或工作区路径搜索，每行显示最近更新时间、工作区名和「运行中」标记，底部显示会话条数与「加入后会打开该会话」提示。支持 ↑/↓ 移动、Enter 确认、Esc 取消、双击某一行直接加入；不再是原生下拉框，会话多时也能看清。
- 加入图片后会自动打开目标会话，不再停留在原处看不到结果。
- 弹窗底色同样垫了不透明层，壁纸皮肤下不会透出工作区。

## 侧栏「会话 / 生图」切换

- 改成带滑动指示块的段控件：选中侧是浮起的表面块（描边 + 轻投影 + 品牌色图标），未选中侧只留灰色文字与图标；切换时指示块左右滑动，不再是一块灰底压白框。
- 图标换成与面板一致的单线图标：会话＝双气泡，生图＝四角星；原来的「相框＋山峰」和方头气泡都已移除。
- 折叠侧栏时两个按钮同样换成新图标，选中侧用品牌色淡底，和宿主原生图标按钮保持同一节奏。

## 验证

- 类型检查、单元测试（新增结果板排版用例）、构建与完整 smoke 检查通过。
- 会话选择与加入链路在 jsdom 与 Chromium（本机 Edge）下各跑一遍：取消不留痕、搜索筛选、选中后加入、加入后打开目标会话。
