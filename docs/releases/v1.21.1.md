# v1.21.1 — 上游重试、存储加固与 edit_image 多图参考

## 修复与加固（合入 #100，感谢 @1634594707）

- **瞬时失败自动重试**：连接失败、408/429/5xx（含 Cloudflare 520–524）最多重试 3 次、指数退避；鉴权、参数、内容审核类错误不重试，不浪费额度。
- **轮询失败原地重试**：异步任务一旦被上游接受，轮询失败不会再走外层重试（不会重复提交、重复计费）；240 秒超时会带上最后状态与最后错误。
- **部分成功保留可用图**：并行出图改用 `Promise.allSettled`，成功的图照常完成，失败的在 `partialError` 里点名，面板与 Agent 工具结果都能看到；`dall-e-3`、经典 Qwen 这类只回一张的模型会明确说明"本次仅返回 N 张"。
- **缺图位置可重试**：工作室把"已完成但该位置没有图"渲染成可重试的失败卡，不再永远转圈。
- **任务队列有界**：内存只保留最近 50 个已结束任务（含 base64 结果），更早的从队列移除，图片仍在磁盘历史里。
- **画廊 / 收藏索引加固**：损坏文件先隔离备份（最多 3 份）再重写；区分"文件不存在"与"读取失败"；写入失败清理临时文件；收藏改为跟随数据根目录、按路径缓存，并一次性导入旧位置的文件；历史 / 画廊删除（含清空）失败会回滚到宿主列表并提示。

## 新增（修复 #99）

- `edit_image` 新增 `reference_images`：最多 4 张额外参考图，与 `source_image` 一起提交（引擎和路由此前已支持，缺的是 Agent 工具层）。
- 工具描述写明多图能力边界：`gpt-image`、`seedream`、`SenseNova` 系列会发送全部参考；`grok-imagine`、`nanobanana`、`minimax`、`dall-e`、`qwen` 只取 `source_image`。
- 所有参考图在提交前并行读取，附件缺失时在计费前失败。
