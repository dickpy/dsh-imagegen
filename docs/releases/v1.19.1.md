# v1.19.1 — 结果预览重做与发布修复

## 生成动画与结果布局

- 修复文生图 / 图生图生成时点阵动画不显示的问题：紧凑动画容器此前高度塌陷为 0，等待卡片里只剩右下角一行文字；现在动画正常铺满等待区域。
- 结果区按图片张数排布：1 张占满整个预览区，2 张左右各半，3 张三列，4 张上下各两张；追加模型超过 4 张时改为三列网格并可滚动。
- 图片保持原始比例完整显示（contain），不裁切；留白与卡片同色，不再出现灰色边框。
- 等待中的「已用时」每秒刷新，不再固定为 0s。

## 结果操作

- 结果卡不再显示一排操作按钮，也不再提供「全屏对比」；全部操作收进图片右键菜单：查看大图、继续编辑、重新生成、复制图片、加入素材库、加入对话、反推提示词、下载。
- 结果卡悬停时右上角出现「⋯」按钮，触屏与键盘用户同样可以打开菜单；菜单支持 Esc 关闭与上下键切换。
- 历史记录、多模型对比与预览灯箱中的图片统一使用同一套右键菜单。
- 预览区左上 / 右上的悬浮按钮（加入素材库、加入对话、继续编辑、反推提示词、复制图片、下载）已移除，统一走右键菜单。
- 「模板」入口从浮层移到结果工具栏，与「追加模型」并排，不再遮挡图片。

## 修复

- 在没有 `requestAnimationFrame` 的环境（如 jsdom 测试）中点击模板不再抛错。
