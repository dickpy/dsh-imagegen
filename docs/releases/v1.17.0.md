# v1.17.0 · 可信远程访问与生图工作台优化

- **合入 PR #69：可信远程 WebUI。** 管理员可在 profile 的 `cordis.patch.yml` 中为 `imagegen` 设置 `remoteAccess: trusted-host`，同时配置 DSH 的可信域名并使用有效浏览器认证，远程使用完整生图工作台。默认仅允许已认证的浏览器所有者读取脱敏设置；非所有者 API Peer、未认证请求、跨站请求和远程提权设置修改均被拒绝。旧宿主缺少认证接口时拒绝远程访问，本机访问保留原行为。
- **实现 #70：单张重试与重新生成。** 失败、取消和已生成结果均可在原卡片重做，仅提交一张，其他结果与排列位置保留。重做沿用原任务的渠道、模型、参数、参考图和遮罩，生成期间保留上一张可用结果。
- **实现 #70：模式隔离与任务视图恢复。** 文生图、图生图各自保留结果、失败状态和任务组。切换工作区、刷新和面板重新挂载后恢复当前标签页的任务视图；后台任务完成不会覆盖另一模式或当前查看的历史结果。任务落在轮询摘要范围之外时按 ID 恢复；宿主已丢失的任务显示失效状态，不再无限等待。已生成图片继续保存在历史记录中。
- **实现 #70：追加模型。** 在当前结果区展开「追加模型」，沿用这组任务的提示词、参考图和参数生成新卡片，保留原结果。
- **实现 #70：渠道排序与实际尺寸。** 结果顺序与渠道 / 模型目录一致，不再受勾选先后影响；同名模型保留渠道身份。卡片显示渠道、模型、实际图片宽高及耗时，历史和画廊保留这些信息。实际像素从返回文件读取，旧图片在浏览器加载后测量，不以请求的 4K / 2K 代替真实尺寸。
- **实现 #70：遮罩编辑。** 普通图生图和无限画布新增画笔遮罩，支持调整笔刷、擦除、撤销和清空。原始像素尺寸的透明 PNG 遮罩贯通编辑请求及重试；不支持的协议 / 订阅渠道明确拒绝。无限画布保存遮罩资产，生成后按遮罩合成回原图，保留遮罩外像素。普通图生图的局部效果由上游原生遮罩实现决定。
- 保留图片预览、全屏对比、复制图片、加入对话、素材库、反推提示词与隐私遮挡，调整结果区与画布工具栏以避免遮挡新增操作。同步中文、英文、俄文文案。

## 远程启用

```yaml
- id: imagegen
  config:
    remoteAccess: trusted-host
```

同时需要 DSH 的 `--trusted-host <域名>` / `trustedHosts` 与有效浏览器认证，并重启 DSH。`--public-url` 本身不授予权限。此授权覆盖配置、生成、上传、技能与更新；请只授权可信浏览器所有者。反向代理应保留真实 Host、Origin 和认证信息。

## 验证

类型检查、构建、单元及路由回归、远程权限矩阵、既有 DOM 端到端与完整冒烟测试、实际工作台的 Chromium 交互回归、npm tarball 内容校验。浏览器回归覆盖失败卡片保留与面板恢复、单张重做、目录排序、追加模型、真实像素、两模式后台完成隔离、遮罩上传及重试、画布遮罩保存与区域外像素保持。

验证采用本地上游响应夹具，未调用真实付费生图接口，也未进行远程 HTTPS 浏览器登录验收。
