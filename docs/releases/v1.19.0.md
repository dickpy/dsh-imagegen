# v1.19.0 · 连续编辑与历史版本

## 连续编辑图片（#88 / #89）

- 结果卡片新增「继续编辑」：直接将选中的结果设为图生图参考图，复用渠道、模型、尺寸、清晰度与数量，填写本轮修改即可继续生成。
- 历史记录按迭代线程分组，保存父版本和多图中的来源位置；支持并排查看结果、单独打开各版本，以及从旧版本继续产生分支。
- 成功图生图任务在宿主保存参考图，刷新或重启后可从历史恢复输入。单张最多 10 MiB、合计最多 16 MiB，超限时保留可识别的父版本引用；删除历史同步清理对应参考文件。
- `/edit_image` 完成后将新图作为附件写入当前会话，连续执行时自动使用最新结果；本次命令显式附图和待发送图片仍优先。
- 直接编辑命令检查真实上游模型的编辑能力，不支持时选择可用编辑模型或明确报错；沿用原图最接近的受支持比例和模型清晰度档位。
- 兼容旧历史；缺少参考图时提示补充，不会静默退化为文生图。

## 暗色主题与设置页（#87）

- 修复暗色主题下主按钮、徽章、画廊头像及下载链接文字与背景混在一起的问题。
- 海报编辑器跟随宿主主题；标签栏、画布背景和点阵光晕随运行中的主题切换更新。
- 设置页保存栏根据宿主滚动容器内边距贴底；为键盘聚焦控件预留滚动空间。
- 修正 PPT 错误颜色令牌并清理主题观察者的生命周期。

## 验证与兼容性

- 两个 PR 的 Web regression / Chromium CI 均通过。
- 发布流水线重新执行类型检查、构建、单元与远程权限测试、DOM E2E、迭代回归、完整冒烟检查及 npm 包完整性校验。
