# v1.17.1 · 适配 DSH 0.2.x 的三栏外框

- **修复生图侧栏空白、没有历史列表。** DSH 0.2.x 把工作区/会话区域包进了新的滚动容器（scrollRegion → scrollArea → regionArea）。插件原来按类名白名单隐藏侧栏里其它条目，把承载历史面板的外层容器一起隐藏了，生图侧栏只剩品牌行、会话/生图切换、新会话和底部账户区。现在挂载时给「侧栏根 → 工作区区域」之间的每一层包装打 `data-dsh-imagegen-sidebar-keep`，白名单按标记放行，不再依赖外壳类名；其它面板的导航行在生图模式下继续隐藏。
- **修复右侧对话栏变成空框。** DSH 0.2.x 在中心列里新增了自己的 `mainPanel` 包装层，对话内容在它里面。插件原来「保留对话根、其余一律隐藏」的规则把整个包装层隐藏了，打开对话栏时只剩一个空白的三栏外框。现在保留该包装层，并由挂载代码从对话根向上走到中心列的直接子节点、打 `data-dsh-imagegen-chat-column` 标记，把它放进第三栏；外壳再次替换包装层时副作用观察器会重新标记。旧壳（`[data-slot="conversation"]` / `[data-slot="main"]`）的选择器全部保留。
- **修复侧栏收起后打不开。** DSH 0.2.x 把收起侧栏的唯一入口放进外框的 leading seat（z-index 15），生图面板 z-index 60 盖住了它，窄窗口下既看不到会话也打不开侧栏。现在把该入口提到生图面板之上；同时按外框公布的 `--dsh-frame-leading-clearance` / `--dsh-frame-top-clearance` 给面板标题行让出 macOS 红绿灯与窗口控件的位置，标题不再压在窗口边框下面。

- **修复电商模式配置列被裁切。** 电商配置列是滚动端口里的一个 flex 项，默认 `min-width: auto` 让它停在 min-content（实测 330px）而不跟随列宽（300px），于是横向溢出、卡片左侧被裁掉一个字；两列参数网格和三列结构 / 素材网格也用 `1fr` 拒绝收窄。现在工作区按列宽收缩（`width: 100%` + `min-width: 0`），三组网格改成 `minmax(0, 1fr)`，配置滚动区禁止横向滚动，列宽拖到 240px 下限也只会重排、不会横移。

## 验证

在 macOS 桌面宿主 DSH 0.2.2-rc.2 的运行窗口中逐项复验：

- 生图侧栏的「历史记录」列表恢复，其它面板的导航行在生图模式下继续让位；
- 顶部「对话」按钮打开后，右侧栏显示真实对话内容，不再是一个空白外框；
- 900pt 窄窗口收起侧栏后，左上角入口可见且可点击，面板标题让开 macOS 红绿灯；
- 1800pt 窗口下三栏几何为工作室 607px / 8px 拖拽条 / 对话 347px，DOM 检测内容无横向溢出；
- 电商模式配置卡片不再被裁掉左边缘，标题与两列参数网格完整显示（修复前实测内容 330px 撑在 300px 列宽里）。

另跑类型检查、构建、单元测试 51 项、会话 / 工具视图 / 参考图三组 DOM 端到端，以及远程权限回归。

未在 Windows 宿主与浏览器版 WebUI 上实机验证。
