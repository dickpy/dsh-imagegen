# v1.16.0 · 记住生成设置、历史参数回填与提示词全窗口编辑

- **实现 #68：生图设置自动记忆。** 模型与渠道、尺寸、清晰度、生成数量、细节和多模型对比选择保存在浏览器本地，重新打开 DSH 或刷新页面后自动恢复，不用每次重新点一遍。渠道或模型被移除时回退到当前配置的默认值，不会卡在已失效的选择上；模型列表还没加载完成时也不会把记住的选择清空。
- **实现 #68：历史记录回填提示词与参数。** 在历史记录里点选一次生成，会把当次的提示词、模式（文生图 / 图生图）、模型、尺寸、清晰度、数量、细节一起载入输入面板，直接点「开始生成」即可复现这次结果；多模型对比记录会连对比模型一并恢复。记录里的模型已从配置中移除时，按当前可用模型回退。
- **修复 #68：历史记录看起来像「多选」的问题。** 多模型对比记录此前一直使用品牌色描边，和「当前载入」的高亮几乎一样，于是几条记录同时像被选中。现在对比记录改用左侧色条标记，当前载入的那一条用品牌色描边 + 淡底色 + 描边环，并且任何时刻只有一条，同时通过 `aria-current` 暴露给辅助技术。
- **提示词全窗口编辑。** 提示词框右下角的手动拖拽把手换成放大按钮：点开是全窗口编辑器，长提示词可以整段阅读和修改，字数统计、增强、清空在编辑器里同样可用；编辑实时同步回面板，Esc、「完成」或 Ctrl/⌘ + Enter 关闭。文生图和图生图共用同一个编辑器。
- 同步中文、英文、俄文文案，插件与更新检测版本统一为 **1.16.0**。

验证：类型检查、构建、43 项单测、3 组 DOM 端到端回归、构建产物冒烟检查及 npm tarball 校验。新增回归覆盖设置持久化的读写/迁移/容错、提示词编辑器与面板的双向同步、历史记录回填提示词与参数、以及对比记录与当前载入状态的区分。

本次未调用真实付费上游进行出图验收。
