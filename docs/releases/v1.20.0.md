# v1.20.0 · 历史记录分页与长期保留

- 历史侧栏每页显示 10 组记录。底部支持上一页、下一页和输入页码跳转。搜索和筛选覆盖全部历史，同一组的图片和迭代版本一起显示。
- 生成历史、结果图和已保存的参考图长期保留。升级沿用现有索引和文件。此前已清理的文件需从备份恢复。手动删除或清空历史时仍会删除对应文件，设置页已补充说明。修复 #94。
- 浏览其他历史后，回到当前结果会恢复结果板，可以从图片菜单继续编辑。修复 #91。
- 渠道或模型列表内部滚动时，选择弹层保持打开。修复 #92。
- README 补充 Windows 桌面版找不到宿主 `pnpm.mjs` 时的排查指引。关联 #90。
