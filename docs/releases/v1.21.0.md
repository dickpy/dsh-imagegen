# v1.21.0 — 侧栏入口改为注册式，兼容 Islands 等换肤侧栏

- **侧栏入口改为官方插槽**：`生图` 不再是注入到原生侧栏 DOM 里的一行，而是注册为真正的全局面板（`sidebar.panellist` + `main` shim）。原生侧栏、Islands UI 以及以后自己画侧栏的皮肤都会自动显示这一项，图标、悬停、排序、显隐都跟着宿主的行样式走。
- **新增「返回会话」**：工作室左上角加了返回按钮；另外在侧栏里点任何导航（会话、工作区、新建会话、设置…）、切换会话、或皮肤派发「回到会话」激活事件时，工作室都会自动退出。之前只有"再点一次生图图标"这一条路。
- **图标换成图片叠放字形**（`Images`），打开工作室时点亮为强调色。
- **入口图标自包含**：图标不依赖插槽注入的运行时数据，因此换肤侧栏直接渲染组件时也能正常显示（Islands UI 就是这么渲染的）。
- 顺带修好：工作室打开时面板列表不再整体隐藏，`插件 / 技能 / 自动化任务 / 生图` 始终可见可点；`更多` 菜单与原生侧栏行为保持一致。
- 已向 `dsh-islands-ui` 提交 PR（DawnCHL/dsh-islands-ui#14）：首页按钮派发会话激活事件、图标按契约注入。
