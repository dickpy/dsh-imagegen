# v1.23.0 — 侧栏交互、结果布局与 Cloudflare Workers AI

## 新增

- **结果区动态多图排版**：按容器宽度和每张图的宽高比动态选择列数；三张竖图同排三列，两张图保持并排并垂直居中，横图保持 2+1 / 2×2，减少底部空白。
- **预览滚轮切图**：文生图 / 图生图结果区可用鼠标滚轮切换上一条 / 下一条历史记录，跨页时历史分页和滚动位置会同步跟随；打开大图后滚轮仍为缩放。
- **Cloudflare Workers AI（实验）**：新增原生 Run API 适配器与 `cloudflare-workers-ai` 预设，先支持 `@cf/black-forest-labs/flux-1-schnell` 文生图；需要 Cloudflare Account ID 与 API Token。
- **侧栏交互**：面板 header 左侧按钮可收起 / 展开最左侧边栏；参数栏收起按钮位于 GitHub 图标右侧，参数栏保留抽屉式过渡。

## 修复

- **#109 侧栏接管回归**：恢复被 v1.22.0 隐藏的窗口按钮带与品牌行；空品牌行会自动收起，避免「回到对话」上方留白。
- **#108 下载 0 字节**：结果卡片、预览、右键菜单、电商、画廊批量与画布节点统一改用 Blob URL / attachment 路由，避免大图 `data:` URL 在自定义保存路径下写成空文件。
- **#106 预览层**：lightbox 放宽到最大 `1680×1200`，关闭按钮移到右上偏左下并扩大点击区域。
- **#107 参数栏布局**：参数栏宽度使用 180ms 抽屉式过渡，拖动 resizer 时禁用过渡；移除重复箭头。
- **#105 结果卡片比例**：实时结果、历史记录和素材详情共用 `ResultSheet`，卡片按原图比例收缩，旧记录按图片自然尺寸补齐。

## 说明

- 本版本不改动历史记录格式，旧历史索引与图片仍可直接使用。
- Cloudflare Workers AI 的 `flux-1-schnell` 当前仅支持文生图；图生图、FLUX.2 multipart 等模型能力后续按需求扩展。
- #107 中提到的历史文件夹分类与图片拖拽属于后续功能，不在本版本范围。
