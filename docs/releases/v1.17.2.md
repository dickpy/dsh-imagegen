# v1.17.2 · 参考图一键反推与统一操作栏

- 解决 #76：图生图参考图区增加「反推提示词」，上传或粘贴后点击一次即可开始，成功后自动填入提示词框，无需先生成图片。多参考图时可明确选择反推对象。
- 将反推、模板库、素材库与生成入口集中在配置列底部，统一按钮尺寸、圆角、配色与图标；参数区滚动时常用入口保持固定，窄列与移动视口自动换行。参考图区的遮罩操作使用同一按钮样式。
- 反推失败时保留原提示词与参考图，支持重试；取消后丢弃晚到结果，上传阶段关闭也不会继续调用视觉模型。未配置视觉聊天模型时显示配置引导。
- 保留结果图、预览、多模型对比与无限画布的反推入口；结果图仍可调整详略、语言和附加要求后手动填入。
